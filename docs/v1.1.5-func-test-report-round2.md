## BUG 清单

### BUG-5（本轮新发现 → lead 已修 → 本轮复核通过）
- **现象（修复前）**：托盘「迷你窗」第 1 次进出正常；**第 2 次进出退出后窗口不再恢复**，永久卡在迷你尺寸（物理 668×913 / 客户区 644×849 = DIP 368×485），此后任意次切换都停在 `bounds={"x":925,"y":332,"width":369,"height":486}`，只能手动拉伸或重启。
- **修复前复现**：2 次独立重启 100% 复现（`%TEMP%\ft2b.log`、`ft2c.log`）；对比 22:45 那次（代码未含 N32）连续 3 次往返均正常 —— 因此判定为 N32 回归。
- **修复内容（lead，`src/main/main.ts`）**：`setMini()` 进入分支先算基准并写回 `normalBounds`/`lastNormalBounds`，**再 `mini = true`，之后才 `applyMiniBounds()`**（`main.ts:634-645`）；退出分支 **先 `mini = false` 再 `setBounds(back)`**，并显式 `lastNormalBounds = back`（`main.ts:665-670`），不再依赖事件派发时序；selftest 增加第二轮往返断言 `miniRoundTrip2OuterAfter` / `miniRoundTrip2BoundsStable`（`main.ts:1939-1948`）。
- **修复后复核（最终代码，23:04，`%TEMP%\ft2f.log`）**：托盘连续 3 次往返，**3/3 全部正常恢复**，无一次卡迷你尺寸：

  | 基线 | 2066×1437 @247,40 | 2042×1373 | 1180.6×821.1 / 1166.9×784.6 |
  | 第 1 次出 | 2068×1441 @247,40 | 2044×1377 | 1181.7×823.4 / 1168×786.9 |
  | 第 2 次出 | 2070×1444 @247,40 | 2046×1380 | 1182.9×825.1 / 1169.1×788.6 |

  三次进入均为 665~666×910~911 物理（DIP 380~380.6×520~520.6），位置稳定在 x1607~1610/y529~536（±3px 抖动）。selftest 侧：`miniRoundTripBoundsStable=true`、位置 x/y 不变。
- **严重度**：已修复（阻断级 → 通过）。

### BUG-4（round1 发现 → 本轮修复，残留降级为 BUG-6）
- **修复前**：每次往返客户区缩 ~13×35 DIP，持续累积。
- **修复后**：`getBounds()` 统一外框语义，13×35 级缩小消失；单次往返差 +1×+2（真机 outer 2066×1437→2068×1441；selftest 1181×823→1182×825），≤2px 达标。剩余增长见 BUG-6。
- **严重度**：已修复。

### BUG-6（本轮新记录，轻微）
- **现象**：迷你窗每往返一次，窗口（外框与客户区同增）**单调增长约 +1~2 DIP**，不会回落。3 次累计：outer 1180.6×821.1 → 1183.4×827.4 DIP（物理 2066×1437 → 2071×1448，**+5×+11 物理像素**）。
- **证据**：`%TEMP%\ft2f.log` 三次 `setMini(false)` 后量测；selftest 同一现象：`miniRoundTripOuterBefore 1181×823` → 第 1 轮 1182×825 → 第 2 轮 **1183×827**，故 lead 新加的 `miniRoundTrip2BoundsStable=false`（判定线 ≤2px，实际 +2×+4）。
- **推断**：`win.getBounds()`（DIP 整数）→ `setBounds` 再换算物理像素时的取整方向不一致（1181 DIP × 1.75 = 2066.75 → 物理取 2067/2068，回读 DIP 又向上取整），每次往返把基线上推 1~2。属取整累积，不影响功能，肉眼不可见，但长期反复切换会让窗口缓慢变大。
- **建议**：退出兜底时可对 `back` 做一次幂等校正（例如用 `setContentSize` 或记录物理像素并回写 `lastNormalBounds`），并把 selftest 两轮判定改为「与首轮 After 比较」；若判定线保留 ≤2px，则现在会一直红。
- **严重度**：轻微（低）。
