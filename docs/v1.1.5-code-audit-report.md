### BUG-2 专项分析（重点审查项）

实现：`quota-store.ts:148-169` 导出纯函数 `sessionEntriesNeedRepair(raw, entries)`；`loadSessions` `:438-467` 先 `readJsonText` 再 `parseSessionTokensFile`，命中则 `saveSessions` 回写。

**答四个问题：**

1. **误判导致每次启动重写？不会。** 坏 `updatedAt` 经 `saneUpdatedAt`（`:123-128`）清洗成整数 `Date.now()` → 回写一次 → 下次 `rawUpdatedAt === entry.updatedAt` 成立 → `false`，不再重写。小数毫秒（`Math.trunc` 后不等）也只在**每个新进程首次** load 时修一次即自愈。
2. **漏判？有三类。**
   - **丢弃条目永久留盘**：`parseSessionTokensFile`（`:171-202`）对「`tokens`/`regenerateUsed`/`editUsed` 全缺」或「convId 不合 `isSafeAccountId`」的条目直接 `continue`；这些条目不在 `entries` 里，`sessionEntriesNeedRepair` 遍历的是**清洗后**的 `entries`，永远看不到它们 → 文件只增不减、不会被修。
   - **结构坏文件不修**：`raw['entries']` 不是对象、或 `parsed === null`、或 `accountId` 与文件名不一致时，`loadSessions` 直接返回空/`null`，**不回写**（`sessionEntriesNeedRepair` 对 `!isRecord` 也返回 `false`）。
   - **淘汰不触发**：`MAX_SESSION_ENTRIES = 200`（`:111`）的淘汰只在 `saveSessions` 里发生，若文件里只有"被 parse 丢弃的垃圾+"，`saveSessions` 可能永不被调用。
3. **回写发生在 getSessionTokens/setSessionTokens 路径上有无副作用/性能问题？可控。**
   - `loadSessions` 被 `getSessionTokens`（`:265`）、`setSessionTokens`（`:273`）、`getSessionActions`（`:299`）、`setSessionActions`（`:316`）调用；`onNavigated`（`main.ts:362/366`）切会话时同步触发。
   - 首次进某账号：一次同步读盘（已存在）+ **可能一次同步写盘**（repair）。若同一次导航里随后又 `setSessionTokens`/`setSessionActions`，会出现「repair 写一次 + set 写一次」两次同步写；`loadSessions` 之后有内存缓存，后续不再读盘。
   - 量级：单账号会话条目 ≤200，`saveSessions` 是 `JSON.stringify` + `.tmp` rename，毫秒级；在窗口导航回调里执行，可接受但属于"读路径上的同步写"，建议把 repair 写盘改成 `setImmediate`/`later` 以免卡导航（轻微）。
4. **回写失败是否被吞掉只告警？是，且每次都重试。** `saveSessions` catch 只 `logger.warn`（`:483`），不置标志。若目录只读，**每个新进程首次** `loadSessions` 都会再试一次并刷一条 warn；不影响主流程（内存里已是清洗后的值）。

### BUG-3 专项分析

- 顺序：`setMini()` 内 `applyViewZoom()`（`:671`）→ `console.log(... zoom=${self.zoomFactorTarget})`（`:673-675`），**日志与目标值同 tick，时序正确**。
- 其他 `applyViewZoom` 调用点都齐了：`setMini`（`:671`）、`dropMini`（`:472`）、`onNavigated`（`:354`，页面导航会按 origin 重置缩放，所以每次导航都要重应用）。**没有遗漏调用点。**
- 唯一问题：`:314` `self.zoomFactor = factor` 让该字段从"真实读回值"退化为"目标值"，与 `zoomFactorTarget`（`:313`）语义重复；自检里 `self.zoomFactor` 若被当作真实值解读会失真（真实值由 `miniZoomFactor`/`zoomAfterMiniExit` 另行读取，见 `main.ts:1945` 起）。属于**轻微**（N18）。
